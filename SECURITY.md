# FitLife Security Policy

## Supported Versions

The latest release (see GitHub Releases) is the only supported version.
Older releases do not receive security updates.

## Reporting a Vulnerability

Please do NOT open a public issue for security vulnerabilities.
Contact the maintainer directly via GitHub (tanish975) or the repository
security advisories (private) with:

- A description of the vulnerability
- Steps to reproduce
- The affected version / commit
- Any suggested fix

We will acknowledge your report within 7 business days and keep you informed
until the issue is resolved. Public disclosure should wait until a fix is
released.

## Scope

- Source code in this repository
- FitLife Android APK and FitLife-App.html releases
- FitLife FoodDB and exercise catalog data

Out of scope: third-party libraries (lucide-react, animejs, qrcode, etc.)
— report those to their respective maintainers.

## Policy

- Responsible disclosure is appreciated.
- No legal action will be taken against good-faith security researchers.
- Do not exploit vulnerabilities beyond what is needed to demonstrate them.
