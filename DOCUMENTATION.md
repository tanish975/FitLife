# Prime - Personal Health & Consistency Coach

Prime is a premium, AI-driven personal health assistant designed to help users track their fitness goals, manage their nutrition, and follow personalized workout plans. Built with a modern glassmorphism aesthetic, Prime offers a seamless and engaging experience for health-conscious individuals.

---

## 🚀 Key Features

### 1. Smart Dashboard
- **Real-time Metrics**: View your daily calorie progress, hydration levels, and health score at a glance.
- **Dynamic Greeting**: Personalized greetings based on the time of day and your profile.
- **Bio-Metrics**: Automatic calculation of BMI, BMR, and Ideal Weight.
- **Quick Actions**: Easy access to log meals, record workouts, and track moods.

### 2. My Health Profile
- **Fine-Tuned Personalization**: Update your age, gender, height, weight, and fitness goals.
- **AI Coach Perspective**: Get immediate, science-based feedback on your current health status and recommendations for your goals.
- **Visual Analysis**: Interactive BMI gauge to visualize your category (Underweight, Normal, Overweight, Obese).

### 3. Nutrition Log (Calories)
- **Daily Budgeting**: Track consumed calories against a personalized TDEE-based target.
- **Meal Categorization**: Log meals by type (Breakfast, Lunch, Dinner, Snack) for better tracking.
- **Consumption Timeline**: Review your daily intake with a clean, chronological history.
- **Consistency Tracking**: Analyze your weekly average intake to stay on path.

### 4. Personal Workout Plans
- **Context-Aware Recommendations**: Workouts tailored to your location (Home vs. Gym) and your BMI/Goals.
- **Interactive Training**: Expand exercises to see AI-optimized rep/set plans and form guidance.
- **Progress Tracking**: Real-time progress bars for each workout session.
- **Stick-Figure Visuals**: Dynamic animations showing the target pose for each exercise.

### 5. Advanced Features
- **Hydration Tracker**: Interactive logging of water intake.
- **Mood Tracker**: Log your daily mood to see how it correlates with your health activities.
- **Achievement System**: Unlock badges as you hit consistency milestones.
- **Report Export**: Export your dashboard metrics as a digital report (PDF/Image support).

## 🛠️ Technology Stack

- **Frontend**: [React 19](https://reactjs.org/)
- **Styling**: [Bootstrap 5](https://getbootstrap.com/) + Custom Glassmorphism System
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Data Fetching**: [TanStack Query (React Query) v5](https://tanstack.com/query/latest)
- **Icons**: [React Bootstrap Icons](https://icons.getbootstrap.com/)
- **Charts**: [Recharts](https://recharts.org/)
- **Storage**: Browser `localStorage` (Service Mocking via `base44Client`)

## 🏁 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

### Running the App
Start the development server:
```bash
npm start
```
The app will be available at `http://localhost:3000`.

### Building for Production
Create an optimized production build:
```bash
npm run build
```

## 🛡️ Architecture & Design Rationale

- **Glassmorphism UI**: Uses semi-transparent panels with backdrop filters to create a high-end, modern depth.
- **Agentic Logic**: The "AI Coach" messages are generated through rule-based logic in `utils/` that interprets user data to provide context-aware advice.
- **Mock Service Layer**: The `base44Client` acts as a complete abstraction for data operations, allowing the frontend to be developed and tested without a live backend, while maintaining "server-like" async behavior.
